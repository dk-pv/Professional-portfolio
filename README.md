# danishpv.dev

Portfolio of Danish Pv — Full Stack Developer building enterprise
applications, ERP systems and real-time platforms.

Live: https://danishpv.dev

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS v4
- Static content from `src/lib/projects.ts` (single source of truth for
  projects, case-study pages and the sitemap)

## Run

```bash
npm install
npm run dev
```

`npm run build` for a production build, `npm run lint` to lint.
